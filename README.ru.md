# dashcam

**Видеорегистратор для ваших ИИ-агентов.**

Трассировка, воспроизведение и отладка стоимости для LLM-приложений и агентов — нулевая настройка, локальность прежде всего.

2 часа ночи, ваш агент упал. *Какой* именно вызов не удался? Что он *на самом деле* отправил? Сколько стоил весь запуск и куда ушли токены?

Автомобильный видеорегистратор молча пишет всё в фоне — а когда что-то пошло не так, вы отматываете запись и видите точно, что произошло. **dashcam делает то же самое для LLM-приложений**: он молча записывает каждый LLM-вызов вашей программы, а затем даёт локальную шкалу времени для воспроизведения, инспекции и поиска причин сбоя.

## Почему dashcam

| | dashcam | LangSmith / Langfuse | отладка через print() |
|---|---|---|---|
| Изменения кода | **не нужны** | SDK / декораторы | повсюду |
| Данные покидают вашу машину | **никогда** | облако или свой сервер | - |
| Зависимости | **ноль** (чистая стандартная библиотека) | сервер + БД + SDK | - |
| Время настройки | 10 секунд | от минут до часов | - |
| Учёт стоимости | встроен | по-разному | вручную |
| Работает с любым фреймворком | да (патчит SDK) | привязка к фреймворку | - |

## Быстрый старт

```bash
pip install dashcam
dashcam demo        # генерирует демо-трейсы, API-ключ не нужен
dashcam             # открывает панель на http://127.0.0.1:8377
```

### Вариант A — ноль изменений кода (рекомендуется)

```bash
dashcam install                          # один раз, пишет .pth-хук
DASHCAM=1 python your_agent.py           # всё. всё записывается
```

На Windows: `set DASHCAM=1 && python your_agent.py`

### Вариант B — одна строка импорта

```python
import dashcam
dashcam.instrument()   # патчит openai / anthropic / litellm / mcp, если установлены
```

### Вариант C — явные границы трейса (опционально)

```python
with dashcam.trace("refund-processing-agent") as tid:
    run_agent()   # все LLM-вызовы внутри попадают в один трейс
```

Без явных границ вызовы группируются автоматически по потоку + интервалу активности — без изменений кода.

## Что вы получаете

<p align="center">
  <img src="docs/screenshot.png" alt="Панель dashcam: шкала времени агента" width="860">
</p>

- **Воспроизведение по шкале времени** — каждый LLM-вызов по порядку, с полными сообщениями запроса, параметрами, инструментами и ответами. Кликните на шаг, чтобы развернуть.
- **Выведенные шаги инструментов** — dashcam сравнивает соседние массивы сообщений и восстанавливает, *что ваш агент делал между вызовами* (запуски инструментов, ходы пользователя) — **без интеграции с каким-либо фреймворком**.
- **Поиск причин сбоя** — неудачные вызовы получают красные карточки с полной ошибкой. Список трейсов показывает ошибки с одного взгляда.
- **Учёт токенов и стоимости** — количество токенов и оценка стоимости в USD на вызов и на трейс для распространённых моделей OpenAI / Anthropic / DeepSeek / Gemini / Qwen. Своя таблица цен — через `DASHCAM_PRICES`.
- **Поддержка стриминга** — потоковые ответы собираются заново и записываются, включая фрагменты tool-calls.
- **Локально и приватно** — всё в одном файле SQLite (`~/.dashcam/traces.db`). Без сервера, без аккаунта, без телеметрии.

## Как это работает

```
                    ваша программа
                         │
        вызовы SDK openai / anthropic / litellm / mcp
                         │
              ┌──────────▼──────────┐
              │  dashcam patcher   │   monkey-patch точек входа SDK
              │  (нулевая          │   запись запроса / ответа / usage
              │   настройка)       │
              └──────────┬──────────┘
                         │
              ┌──────────▼──────────┐
              │  SQLite-хранилище  │   ~/.dashcam/traces.db (WAL)
              └──────────┬──────────┘
                         │
              ┌──────────▼──────────┐
              │  локальная панель   │   http.server из stdlib, порт 8377
              │  replay · cost     │   список трейсов, шкала, экспорт JSON
              └─────────────────────┘
```

dashcam патчит клиентские классы установленных SDK в момент импорта. Поведение вашей программы не меняется — если сам dashcam упадёт, он упадёт молча, а ваш агент продолжит работу.

### Поддерживаемые SDK

| SDK | точки входа | синхронно | асинхронно | стриминг |
|---|---|---|---|---|
| openai >= 1.0 | `chat.completions.create`, `responses.create` | ✅ | ✅ | ✅ |
| anthropic | `messages.create`, `messages.stream` | ✅ | ✅ | ✅ |
| litellm | `completion`, `acompletion` | ✅ | ✅ | ✅ |
| mcp >= 1.0 | `ClientSession.call_tool`, `list_tools`, `read_resource` | — | ✅ | — |

Всё, что идёт через эти точки (LangChain, AutoGen, CrewAI, OpenAI-совместимые эндпоинты через litellm, ...), захватывается автоматически.

## ⚙️ Настройка

| Переменная окружения | По умолчанию | Значение |
|---|---|---|
| `DASHCAM` | не задана | При значении `1` хук `.pth` автоматически инструментирует при старте интерпретатора |
| `DASHCAM_DB` | `~/.dashcam/traces.db` | Расположение базы SQLite |
| `DASHCAM_PRICES` | встроенная таблица | Путь к JSON-таблице цен: `{"подстрока-модели": [вход_за_1M_токенов, выход_за_1M_токенов]}` |

Сопоставление цен — по подстроке, побеждает самый длинный ключ (например, `gpt-4o-mini` побеждает `gpt-4o`). Цены приблизительные — для биллинговой точности переопределите своей таблицей.

## FAQ

**Это замедлит моего агента?**
Запись — одна вставка SQLite на LLM-вызов (микросекунды). Сами LLM-вызовы занимают сотни миллисекунд. Вы ничего не заметите.

**А если dashcam сломается?**
Вся внутренняя логика dashcam обёрнута защитно — если внутри dashcam что-то бросит исключение, оно будет поглощено, и ваша программа продолжит работу без последствий.

**Данные куда-то отправляются?**
Нет. Никаких сетевых вызовов, телеметрии и аккаунтов. Панель слушает только на 127.0.0.1.

**Как вызовы группируются в трейсы?**
Явно через `dashcam.trace(name)`, или автоматически: вызовы одного потока в пределах 5-минутного окна активности попадают в один трейс. Неактивные трейсы закрываются сами.

**А потоковые ответы?**
Чанки (текст, фрагменты tool-calls, usage) накапливаются и записываются по завершении потока. Для OpenAI учитывается `stream_options={"include_usage": True}`.
